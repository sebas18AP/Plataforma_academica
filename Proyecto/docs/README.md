# Plataforma Académica

## Inicio rápido en Windows

1. Desde el directorio `Proyecto`, ejecuta `start_app.bat`.
2. El script creará un entorno virtual en `.venv` si no existe.
3. Instalará `pip`, `setuptools`, `wheel` y las dependencias de `requirements.txt`.
4. Finalmente iniciará la aplicación Flask con `python app.py`.

> La primera vez puede tardar un poco, pero después solo necesitarás ejecutar `start_app.bat`.
