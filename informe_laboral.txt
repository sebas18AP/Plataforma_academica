Fecha: 9 de mayo de 2026

DESCRIPCIÓN DEL PROYECTO:
El proyecto es una "Plataforma de Monitoreo Académico" para la Facultad de Ingeniería Eléctrica de UNITEC. No es un sistema completo de gestión empresarial (ERP), sino que se enfoca solo en aspectos académicos y estadísticos, como seguimiento de estudiantes, cursos y calificaciones.

ACTIVIDADES REALIZADAS HOY:

1. ANÁLISIS INICIAL DEL PROYECTO:
   - Se revisó la estructura de archivos existente en el proyecto.
   - Archivos encontrados: main.py (archivo principal), carpetas models/ (lógica), views/ (interfaz), data_base/ (datos).
   - Por qué: Para entender cómo estaba organizado el código y qué partes ya existían, facilitando la planificación de mejoras.

2. EJECUCIÓN Y PRUEBA DEL CÓDIGO EXISTENTE:
   - Se ejecutó el archivo main.py para ver cómo funcionaba el proyecto actual.
   - Resultado: El programa imprimió mensajes de inicio, pero era muy básico.
   - Por qué: Para verificar que el código funcionara y identificar qué necesitaba mejoras, especialmente en la interfaz visual.

3. EXPLICACIÓN DE CONCEPTOS TÉCNICOS:
   - Se explicó qué significa "outline" en el editor de código (VS Code): es una vista que muestra la estructura del archivo, como clases y funciones.
   - Se discutió la organización de archivos: se confirmó que la estructura actual (separar lógica, interfaz y datos) es buena para proyectos pequeños.
   - Por qué: Para educar al equipo sobre herramientas y buenas prácticas, asegurando que todos entiendan el proyecto.

4. CAMBIO DE DIRECCIÓN DEL PROYECTO:
   - Inicialmente, el proyecto usaba Python con Tkinter para interfaces de escritorio.
   - Se decidió cambiar a una aplicación web usando Flask (para el backend) y Tailwind CSS (para el frontend).
   - Por qué: Una plataforma universitaria necesita ser accesible desde cualquier dispositivo con navegador web, no solo desde una computadora con Python instalado. Flask es simple para crear servidores web, y Tailwind hace diseños modernos sin complicaciones.

5. DESARROLLO DE LA PANTALLA DE LOGIN:
   - Se creó el archivo app.py: código en Python con Flask para iniciar un servidor web que muestra la página de login.
   - Se creó la carpeta templates/ y el archivo login.html: página web con diseño minimalista usando Tailwind CSS.
   - Diseño implementado:
     - Fondo gris claro para toda la página.
     - Tarjeta blanca central con bordes redondeados y sombra.
     - Icono de rayo (⚡) representando Ingeniería Eléctrica.
     - Campos de usuario y contraseña con estilos suaves.
     - Botón azul para iniciar sesión.
     - Enlace para "¿Olvidaste tu contraseña?".
   - Comportamiento: Todos los botones y acciones muestran una alerta "el boton funciona correctamente" (prototipo visual, sin lógica real).
   - Por qué: Como prototipo, se priorizó el aspecto visual para validar el diseño antes de agregar funcionalidades complejas. El estilo premium/institucional refleja la seriedad de una universidad.

6. INSTALACIÓN DE DEPENDENCIAS Y PRUEBA:
   - Se instaló Flask (librería de Python para crear aplicaciones web).
   - Se ejecutó el servidor en http://127.0.0.1:5000 para probar la interfaz.
   - Por qué: Para asegurar que el código funcione correctamente y que el equipo pueda ver los resultados inmediatamente.

LOGROS ALCANZADOS:
